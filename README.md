# QuestFit — Gamified Fitness RPG Platform

QuestFit transforms real-world fitness activities into an immersive RPG gaming experience. Workouts generate XP, improve character attributes, unlock legendary gear, complete quests, and contribute damage to cooperative boss battles.

## Tech Stack
- **Frontend**: React, Vite, Tailwind CSS, Framer Motion, Lucide React, Recharts
- **State & Storage**: React Context API with LocalStorage persistence

## Getting Started

1. **Extract the ZIP file** into your local directory.
2. **Open the folder** in **Visual Studio Code**.
3. **Install dependencies**:
   ```bash
   npm install
   ```
4. **Run the development server**:
   ```bash
   npm run dev
   ```
5. Open your browser and navigate to `http://localhost:5173`.
